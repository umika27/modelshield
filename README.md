# ModelShield

> A better model score doesn't always mean a better model.

ModelShield is an adaptive ML verification layer that discovers hidden
model failures, investigates them with targeted tests, verifies them
reproducibly, and turns verified failures into regression tests for
future model releases.

## Core Loop

DISCOVER → INVESTIGATE → VERIFY → REMEMBER → PROTECT
